## 🔴 P0 核心任务：图标系统重做

### 问题现状

首页当前有 **15+ 个彩色图标**，全部使用：
- 糖果色调（粉/紫/蓝/绿）
- 圆角方块背景
- emoji 风格

**视觉师判断**：
> "最大硬伤——9 个圆角粉/紫/绿/蓝彩色 emoji 风图标，与品牌完全违和。彻底偏向 SaaS 工具站，丢掉东方禅意。"

**小雅（真实用户）判断**：
> "米白底 + 黑字 + 紫色小图标，挺干净的，像个读书 App，不像命理。"

### 要求

**方向 A：单色描边线性图标（首选）**
- 统一用 `#1A1A1A`（深黑）或 `#666666`（次黑）单色描边
- 线宽 1.5-2px
- 风格参考：Lucide、Phosphor Icons Light、Heroicons Outline
- 去掉所有圆角方块背景

**方向 B：东方符号系统（进阶）**
- 用简化的东方符号替代具象图标：
  - 八字分析 → ☯ 或 天干地支符号（甲乙丙丁）
  - 每日运势 → ☀ 月相符号
  - 合婚配对 → 双鱼/阴阳双环
  - 塔罗占卜 → ✦ 星星/月亮
  - 紫微斗数 → 北斗七星图
  - 梅花易数 → 八卦符号（☰☱☲☳）
  - 六爻 → 爻线符号（⚊ ⚋）
- 手绘感 / 水墨感 / 极简几何 三选一

**推荐组合**：方向 A 打底 + 方向 B 作为主打功能点缀

### TASK-2 视觉样式参考图（供代码虾实现）

  - 水墨晕染纹理

- 要求：克制、不花哨，作为视觉锚点
