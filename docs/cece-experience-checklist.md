# 测测 App 深度体验清单（补充版）

基于初步研究，这是你实际体验时需要重点关注的功能和细节。

---

## 📱 核心功能体验清单

### 1. 星座/运势模块
**必须体验：**
- [ ] 每日运势的内容深度（多少字？有图吗？）
- [ ] 是否有周运势、月运势、年运势
- [ ] 运势分类（爱情、事业、财运、健康等）
- [ ] 运势更新频率和时间
- [ ] 是否有运势提醒推送

**观察重点：**
- 免费运势 vs 付费运势的区别
- 内容是否个性化（基于生辰八字）

---

### 2. 测算/占卜模块
**必须体验：**
- [ ] 有哪些测算类型（塔罗、八字、紫微、姓名等）
- [ ] 每种测算的流程（输入什么信息？）
- [ ] 测算结果的呈现方式（文字/图表/视频）
- [ ] 免费测算 vs 付费测算的数量和质量差异

**观察重点：**
- 哪些测算免费？哪些付费？
- 付费测算的价格区间
- 测算结果是否可以保存/分享

---

### 3. 付费转化设计
**必须截图：**
- [ ] 第一次遇到付费弹窗的场景
- [ ] 付费弹窗的文案和设计
- [ ] 会员页面的完整截图
- [ ] 单次付费的价格列表

**观察重点：**
- 付费弹窗出现的时机（何时触发）
- 文案如何制造紧迫感和价值感
- 是否有"首单优惠"或"限时折扣"
- 支付流程是否顺畅

---

### 4. 会员体系
**必须了解：**
- [ ] 会员分几档？（月卡/季卡/年卡）
- [ ] 每档价格是多少？
- [ ] 会员权益有哪些？
- [ ] 会员标识在哪里展示？

**观察重点：**
- 会员权益是否有吸引力
- 会员 vs 非会员的体验差异有多大
- 是否有自动续费陷阱

---

### 5. 用户留存机制
**必须体验：**
- [ ] 是否有每日签到？奖励是什么？
- [ ] 是否有任务系统？（新手任务/日常任务）
- [ ] 推送通知的内容和频率
- [ ] 是否有社区/广场功能

**观察重点：**
- 签到奖励是否有吸引力
- 任务设计是否引导付费
- 推送是否过度打扰

---

### 6. 社交裂变
**必须体验：**
- [ ] 是否有分享功能？分享有奖励吗？
- [ ] 是否有邀请好友机制？
- [ ] 是否可以送礼物/测算给好友？

**观察重点：**
- 分享的动机设计（为什么要分享）
- 邀请奖励是否有吸引力

## 🎯 重点问题（需要回答）

1. **用户为什么每天打开？**
   - 每日运势？
   - 签到奖励？
   - 推送提醒？
   - 社区内容？

2. **用户为什么付费？**
   - 测算准确度？
   - 大师咨询？
   - 会员特权？
   - 情感需求？

3. **用户为什么复购？**
   - 内容持续更新？
   - 会员权益有价值？
   - 形成使用习惯？
