## 1. 产品定位

### 1.1 一句话定义
> **CyberFate App 是每个中国人的命运随身笔记 —— 每日运势推送 + 命盘沉淀 + Fate 社交。**

### 1.2 为什么要做 App
| 原因 | 说明 |
|------|------|
| **推送留存** | Web 无法推送，每日运势是日活钩子 |
| **Widget 护城河** | 桌面/锁屏小组件是命理 App 的核心差异化 |
| **付费转化** | App 订阅转化率是 Web 的 2-3 倍 |
| **沉浸体验** | 相机、传感器、离线等 Web 做不到 |
| **品牌资产** | 装机量即护城河 |

### 1.3 Web vs App 定位分工

| 维度 | Web | App |
|------|-----|-----|
| 核心角色 | 获客漏斗 / SEO 承接 / 分享落地 | 留存堡垒 / 付费主场 |
| 目标用户 | 第一次接触者 / 搜索来的 | 深度用户 / 老用户 |
| 核心玩法 | 单次测算 + 内容阅读 | 每日运势 + 命盘沉淀 + 社交 |
| 商业化 | Stripe 一次性解锁 | 订阅为主 + 单次解锁 |
| 分享形态 | URL 链接 | 分享卡图 + 深链 |

## 2. 用户画像（App 场景）

### 2.1 核心用户（P0）
- **重度命理爱好者**（25-40 岁，已装知命/准了等 App）

  - 痛点：想看看最近运势但懒得主动查
  - 吸引点：推送提醒 + 一眼可见的 Widget

### 2.3 潜力用户（P2）
- **尝鲜科技玩家 / KOL**
  - 吸引点：朋友合盘 / 分享卡裂变

## 4. 信息架构

### 4.1 底部 Tab Bar（5 Tab 社交化）

```
┌──────┬──────┬──────┬──────┬──────┐
│ 首页 │ 运势 │ 命盘 │ 广场 │ 我的 │
│  🏠  │  ☀️  │  🎴  │  🌐  │  👤  │
└──────┴──────┴──────┴──────┴──────┘
```

#### 4.1.1 首页 Tab `/home`
- 目标：**信息流 + 入口导航**
- 内容：
  - 顶部问候语 + 今日天气/节气
  - 今日运势卡（缩略，点击跳运势 Tab）
  - 功能入口（九宫格：八字/紫微/塔罗/六爻/梅花/合婚/黄历/排盘/更多）
  - 本周命运速递（AI 生成，3 条）
  - 热门测算推荐

#### 4.1.2 运势 Tab `/fortune`
- 目标：**每日高频打开的核心留存页**
- 内容：
  - 顶部日期切换（前 7 天 - 后 7 天）
  - 今日综合运势评分（环形图）
  - 五维运势条（事业/财运/爱情/健康/人际）
  - 宜忌标签（Tag 云）
  - 吉时/吉方位
  - AI 今日建议（含一句金句）
  - **签到按钮**（streak 徽章）
  - 分享卡按钮

#### 4.1.3 命盘 Tab `/chart`
- 目标：**用户的"命运档案"核心**
- 内容：
  - 我的八字命盘（四柱 + 十神 + 五行雷达）
  - 已测命盘列表（家人/朋友）+ 新增按钮
  - 切换查看不同人的命盘
  - 深度解读按钮（付费解锁）
  - 命盘对比（合婚/合盘）

#### 4.1.4 广场 Tab `/square`
- 目标：**社交化核心，MVP 轻量，V2 深度化**
- MVP 内容：
  - 命运话题墙（如"今日适合做的决定"，用户匿名分享）
  - 每日一签榜（我的连续签到 + 好友签到）
  - 命格相似推荐（"和你八字相似的人在看..."）
- V2 内容：
  - 陌生人命格匹配
  - 关注/被关注流
  - 命理师入驻

#### 4.1.5 我的 Tab `/me`
- 目标：**用户资产 + 商业化入口**
- 内容：
  - 头像 / 昵称 / 命运主页链接（分享入口）
  - 我的命盘入口（快捷进 Tab 3）
  - 我的订单 / 已解锁报告
  - 会员中心（核心付费入口）
  - 测算历史
  - 设置（账号/隐私/推送/深色模式）
  - 反馈 / 关于 / 客服

## 5. 首次启动流程

### 5.1 Onboarding 漏斗

```
启动页（2s Logo）
  ↓
引导页 3 屏（可跳过）
  ↓
生辰输入（必填，核心转化点）
  ↓
首次命盘生成（Loading 3s，营造仪式感）
  ↓
AI 解读精简版（3 段话，抓住用户）
  ↓
软性注册引导（"保存命盘需要注册"）
  ↓
进入首页 Tab
```

### 5.2 关键设计要点
- 引导页 3 屏：
  - 屏 1："每日运势，推送不错过"
  - 屏 2："AI 命理，传统+现代"
  - 屏 3："我的命运，可分享可沉淀"
- **注册软性化**：前 3 次测算免注册（游客态存本地），第 4 次强制
- **不要开场要权限**：推送权限在首次看完今日运势后才请求

## 7. 推送通知策略

### 7.1 推送类型与频率

| 类型 | 时机 | 频率 | 可关闭 |
|------|------|------|--------|
| 每日运势 | 每早 8:00 | 每日 | ✅ |
| 吉时提醒 | 动态（当日吉时前 15 分钟） | 每日 0-3 条 | ✅ |
| 节气/节日 | 节气当日 6:00 | 不定 | ✅ |
| 本命年/冲太岁 | 关键日 7:00 | 不定 | ✅ |
| 签到提醒 | 晚 20:00（仅当日未签到）| 每日 | ✅ |
| 好友 Fate 更新 | 实时（社交功能上线后）| 不定 | ✅ |
| 运营活动 | 促销/新功能 | 最多 2/周 | ✅ |

### 7.2 推送文案库（首发 30 条）
- 运势类（10 条）：
  - "今天财气旺，留意微信红包 🧧"
  - "水逆退散，适合告白的一天 💫"
  - "感官敏锐日，直觉比理智更准 🔮"
  - ...（完整 30 条后续补充）

### 7.3 关闭率控制
- 目标：每日运势推送关闭率 <15%
- 策略：
  - 首次推送走"个性化开场"而非通用模板
  - 文案随机池 7 套以上轮播
  - 用户关闭 2 天给一次"降低频率"引导（而非直接关）

## 14. 隐私合规（重要）

### 14.1 必做项
- 启动前：弹窗《用户协议》+《隐私政策》勾选
- 生辰信息：明确告知用途（计算命盘、不外泄）
- 位置信息：可选授权（不给也能用）
- 第三方 SDK 清单：推送 / 支付 / 统计 各一条必披露

### 14.2 《隐私政策》App 专版
- Web 版已有 `/privacy`，但 App 必须有独立版本
- 新增条款：
  - 设备信息收集（IMEI/IDFA）
  - 推送通知权限
  - 位置信息使用
  - Widget 数据本地缓存

### 14.3 数据安全
- 生辰等命理数据必须加密存储（AES-256）
- 云端数据库行级加密
- 删除账号 → 30 天内物理删除所有数据
