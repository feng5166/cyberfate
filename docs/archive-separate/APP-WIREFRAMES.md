## 八、关键交互说明

### 8.1 导航规则
- Tab 切换不保留历史栈（每个 Tab 独立路由）
- 单个 Tab 内部页面有返回栈（最多 5 层）
- 长按 Tab 图标 = 快捷菜单（V2）

### 8.2 手势
- 下拉刷新 = 运势 Tab 刷新今日数据
- 左右滑动 = 运势 Tab 切换日期
- 双击 Tab = 回到该 Tab 顶部

### 8.3 状态保留
- 命盘 Tab 切换的"当前查看人"在 App 重启后保留
- 运势 Tab 默认回到今日（不保留昨天浏览状态）

## 九、深色模式

所有页面必须同时设计深浅两套，遵循 Web v6 Design Tokens：
- 浅色：暖米白 #FAF6EE / 深藏蓝文字
- 深色：深藏蓝 #1B2540 底 / 暖米白文字
- 共用：赭橙 #E87722 作为 CTA 强调色
