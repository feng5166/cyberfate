## 二、CI/CD（M1 必交）

### 2.1 工具栈
- **Expo EAS Build**（云端打包，免本地环境）
- **GitHub Actions**（触发 EAS）
- **EAS Submit**（自动提交到内测渠道，可选）

### 2.2 配置任务
- [ ] 注册 Expo 账号 + 创建 EAS 项目
- [ ] 配置 `eas.json`（preview / production 两个 profile）
- [ ] GitHub Actions 工作流：
  - `push to develop` → EAS 打 preview APK → 上传到飞书云盘
  - `push to main` → EAS 打 production APK → 准备分发
- [ ] 飞书机器人通知（构建成功/失败）

### 2.3 验收标准
- 团队任何人 push 代码 → 30 分钟内收到飞书构建通知
- 内测人员能直接下载 APK 安装

| 渠道 | 注册费 | 审核周期 | 备注 |

| **官网直下** | - | - | 自建 H5 下载页 |

### 5.2 上架材料清单
- [ ] App 名称：CyberFate · 命运笔记
- [ ] 应用分类：**生活服务** 或 **娱乐**（避开"占卜"）
- [ ] 应用描述：传统文化体验（非算命）
- [ ] 应用图标：1024×1024 PNG（美术虾交付）
- [ ] 应用截图：5-8 张 1080×2400（美术虾配合）
- [ ] 隐私政策 URL：cyberfate.me/app/privacy（与 Web 共用）
- [ ] 用户协议 URL：cyberfate.me/app/terms
- [ ] SDK 清单披露
- [ ] 软件著作权（如审核要求）

### 5.3 审核风险预案
- 如被打"占卜"标签 → 调整描述 + 申诉
- 如被要求宗教备案 → 文化娱乐定位申辩
- 多渠道并行，至少 2 个过审即可上线

### 5.4 官网下载页
- [ ] 在 cyberfate.me 添加 `/app` 下载落地页
- [ ] 二维码扫码下载
- [ ] iOS 占位"敬请期待"
