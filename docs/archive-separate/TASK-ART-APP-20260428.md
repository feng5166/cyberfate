## 一、任务总览

为 CyberFate 安卓 App MVP 提供视觉资产，整体风格沿用 **Web v6 Design Tokens**（暖米白 + 深藏蓝 + 赭橙 + 衬线字体），但适配移动端紧凑场景。

**交付节奏：**
- M1（Week 1-2）：图标 + Tab + 启动屏（代码虾搭骨架要用）
- M2（Week 3-4）：引导页 + 空状态插画
- M3（Week 5-8）：分享卡模板 + 会员页视觉

---

## 二、设计原则

### 2.1 必守
- ✅ 沿用 Web v6 Design Tokens（不另起炉灶）
- ✅ 衬线字体（思源宋体 + Cormorant Garamond）
- ✅ 暖米白 #FAF6EE 主背景
- ✅ 深藏蓝 #1B2540 主文字
- ✅ 赭橙 #E87722 仅用于 CTA / 关键强调
- ✅ 大量留白，文化感 > 工具感

### 2.2 必避
- ❌ 不要做"赛博暗紫"老风格
- ❌ 不要堆 emoji 和卡通元素
- ❌ 不要用纯黑底（Frank 明确禁止）
- ❌ 不要用渐变 + 霓虹（与 v6 调性冲突）

---

## 三、交付清单

### 3.1 P0 — Week 1-2 必交（代码虾搭骨架要用）

#### A. App 图标
- 规格：1024×1024 PNG
- 格式：圆角 + 透明背景两版
- 风格建议：太极/八卦元素 + 暖米白底 + 深藏蓝主体 + 赭橙点缀
- 派生尺寸（自动生成）：512 / 192 / 144 / 96 / 72 / 48

#### B. 启动屏（Splash Screen）
- 竖版：1080×2400（覆盖主流安卓机）
- 横版：2400×1080
- 规范：Logo 居中 + 暖米白底 + 底部"命运笔记"副标题（衬线字）

#### C. 5 Tab Bar 图标
| Tab | 默认态 | 选中态 | 含义 |
|-----|--------|--------|------|
| 首页 | 简笔小屋 outline | 实心 + 赭橙 | 家 |
| 运势 | 太阳 outline | 实心 + 赭橙 | 阳 |
| 命盘 | 八卦 outline | 实心 + 赭橙 | 命 |
| 广场 | 网格圆 outline | 实心 + 赭橙 | 群 |
| 我的 | 人形 outline | 实心 + 赭橙 | 己 |

- 规格：SVG 矢量 + PNG 24/48/72px 三档
- 默认态：深藏蓝 50% 透明
- 选中态：赭橙 100%

### 3.2 P0 — Week 3-4 必交

#### D. Onboarding 引导页 3 屏
对应线框图屏 2-4：

**屏 1 / 每日运势推送**
- 主题：晨曦山水
- 元素建议：山 + 朝霞 + 一只鸟（轻盈）
- 色调：暖米白 + 淡赭橙

**屏 2 / AI 命理传统×现代**
- 主题：星图叠加八字命盘
- 元素建议：抽象星座连线 + 干支字
- 色调：深藏蓝 + 暖米白

**屏 3 / 命运可分享**
- 主题：命运卡片漂浮
- 元素建议：手机界面缩影 + 飘出的卡片
- 色调：暖米白 + 赭橙点缀

- 规格：1080×2400 PNG，可单独提供 1080×1080 主体插画 PNG（透明）

#### E. 空状态插画（5 张）
| Tab | 空状态 | 建议元素 |
|-----|--------|---------|
| 首页 | 首次进入 | 一片空白山水 |
| 运势 | 未填生辰 | 一个空命盘 |
| 命盘 | 未生成 | 八卦半透明 |
| 广场 | 暂无内容 | 一片云 |
| 我的 | 未登录 | 一把椅子 |

- 规格：512×512 PNG 透明，配 1 句温柔文案

### 3.3 P1 — Week 5-8 交付

#### F. 分享卡模板（运势 + 命盘）
- **运势分享卡**：1080×1920 长图模板
  - 顶部 Logo + 日期
  - 中部综合评分大圆 + 五维条
  - 底部 AI 建议金句 + 二维码
- **命盘分享卡**：1080×1920
  - 顶部 Logo
  - 中部四柱命盘 + 五行雷达
  - 底部"我的命运主页"二维码

#### G. 会员页视觉
- 核心 Hero：3 个会员卡（月/年/终身）
- 视觉：月卡淡灰、年卡突出（推荐）、终身金色边框
- 配图：一张"命运笔记本"摄影概念图

### 3.4 P2 — V2 再做

- Widget 视觉（小/中/大三种尺寸）
- 主题皮肤包（春/夏/秋/冬 4 套换肤）
- 节气特别配图（24 张 → 慢慢补）

## 四、Design Tokens v6 速查表

### 颜色
```
背景：
  base       = #FAF6EE  (暖米白)
  base-alt   = #F2EDE0  (深一档)
  ink        = #1B2540  (深藏蓝主文字)

文字：
  primary    = #1B2540
  secondary  = #5A5A5A
  muted      = #9E9E9E

强调：
  accent     = #E87722  (赭橙 CTA)
  accent-bg  = rgba(232,119,34,0.08)

五行：
  wood   = #6B8E5A
  fire   = #C0392B
  earth  = #C9A86C
  metal  = #BDB7A4
  water  = #4A6FA5
```

### 字体
```
中文：思源宋体 (Source Han Serif)
英文：Cormorant Garamond
无衬线（次要）：思源黑体 + Inter
```

### 圆角
```
sm = 4px
md = 8px
lg = 12px
xl = 16px
2xl = 24px (大卡片)
```

### 阴影
```
轻：0 1px 2px rgba(27,37,64,0.05)
中：0 4px 12px rgba(27,37,64,0.08)
重：0 8px 24px rgba(27,37,64,0.12)
```
