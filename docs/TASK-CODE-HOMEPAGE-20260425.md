## 🔴 P0 任务（本周内完成）

### TASK-1 删除假用户评价 ⚠️ 信任事故优先级

**现状**：首页"用户评价"区块三条评价存在问题：
- "李女士"出现两次
- 三条评价文案几乎一字不差（"八字分析很准"类）

**要求**：
- 立即删除当前三条假评价
- 临时方案：整个"用户评价"区块**先隐藏**（不展示好过展示假的）
- 最终方案（本周内）：接入真实反馈
  - 方案 A：从反馈留言区筛选 3-5 条正面评价展示（需加审核开关）
  - 方案 B：嵌入小红书笔记卡片（需 Frank 确认版权）
  - 方案 C：做"最近 24h 分析案例"脱敏 feed（虚构命盘信息 + 真实生成内容摘要）

**验收标准**：
- [ ] 当前三条假评价已删除
- [ ] 评价区块要么隐藏要么展示真实内容
- [ ] 真实评价方案落地（3 选 1）

**优先级**：P0，今晚或明早第一件事

---

### TASK-2 Hero 改造为"首屏即漏斗第一步"

**现状**：
- 主副标题太官方："AI 驱动的八字命理、每日运势、塔罗占卜 — 东方智慧，科学态度"
- CTA "免费开始解析" + "梅花易数" 并列，梅花易数不是主打功能
- 用户要点击 CTA 跳转到 /bazi 才能开始，转化路径长

**改造方案**：

**A. 主标题换情绪钩子**（文案产品虾出）
- 当前："CYBERFATE 赛博命理师"
- 新版：保留 CYBERFATE logo，副标题改为：
  > **"输入你的生辰，让 AI 为你解一次命"**

**B. 生辰输入框直接嵌入 Hero**（核心改动）
- 在 Hero 区域嵌入简化版八字输入（年/月/日/时 + 性别）
- 用户填完点"开始分析"直接跳到 /bazi?prefill=xxx 并自动触发分析
- 不再需要二次跳转

**C. CTA 按钮调整**
- 主：「免费开始分析」（字号加大，"免费"加粗强调）
- 次：「看看示例报告」（跳转到一个脱敏的 demo 报告页）
- 删除"梅花易数"入口（移到下方功能卡片区）

**验收标准**：
- [ ] Hero 副标题已更换
- [ ] 生辰输入框嵌入 Hero 首屏可见
- [ ] 填表后能直接跳转到 /bazi 并预填充数据
- [ ] "免费"字样在主 CTA 明显可见
- [ ] 梅花易数不再占据 Hero 副 CTA 位置
- [ ] 示例报告页可访问

**优先级**：P0，下周完成

### TASK-4 JS Bundle 瘦身

**现状**：首页 JS 758KB / 16 chunks，Next.js 默认未做充分 code split

**要求**：
- 跑 `@next/bundle-analyzer` 分析大依赖
- 首页只留 landing shell，非首屏功能（塔罗/紫微/合婚面板）全部用 `dynamic()` 懒加载
- 目标：首页 JS < 400KB

**验收标准**：
- [ ] bundle-analyzer 报告 commit 到仓库
- [ ] 首页 JS 总量 < 400KB
- [ ] Lighthouse Performance > 90

---

### TASK-5 功能卡区块重构

**现状**：9 个功能卡 × 3 组平铺，无主次、无"今日推荐"

**要求**：
- 顶部加"🔥 最多人用"模块（展示 Top 3：八字/每日运势/合婚）
- 区分"主打功能"和"更多工具"的视觉权重（主打用大卡片+缩略图，工具用小卡片）
- 合婚配对 **提升到主打区**（Hero 或主打卡 Top 3），当前它埋得太深

**验收标准**：
- [ ] Top 3 主打功能视觉突出
- [ ] 合婚配对出现在首屏可达位置
- [ ] 非核心功能（紫微/梅花/六爻）收纳到"更多工具"
