## 1. 算法复用核查结论（已核，可直接复用，无需重写算法）
现有 `src/lib/bazi/` 已提供本次所需全部底层算法：
- **四柱**：`calculateBazi(input): BaziResult` → `chart{year,month,day,hour}`，每柱 `{gan,zhi,ganWuxing,zhiWuxing}`（types.ts Pillar）
- **五行统计**：`countWuxing` → `WuxingCount{metal,wood,water,fire,earth}`（雷达图数据源）
- **日主/生肖**：BaziResult.dayMaster / zodiac
- **十神**：`helpers.ts` 的 `getTenGod(dayGan, targetGan)` → 返回 比肩/劫财/食神/伤官/正财/偏财/正官/七杀/正印/偏印
- **藏干**：`geju.ts` 的 `DIZHI_HIDDEN_GAN[zhi]` → 每地支 1-3 个藏干（本气/中气/余气）
- **格局**：geju.ts 已有
→ 结论：命盘、五行、十神、藏干全部复用现成算法，后端只需「调用 + 组装成结构化返回」，不重写命理逻辑。

## 3. 数据结构（后端 API 返回，src/app/api/bazi/marriage/route.ts）
```ts
{
  // —— 命盘（复用 calculateBazi）——
  male: {
    name, gender, zodiac, dayMaster,
    pillars: { year:{gan,zhi,ganWuxing,zhiWuxing}, month:{...}, day:{...}, hour:{...}|null },
    wuxing: { metal, wood, water, fire, earth },     // 雷达图
    shishen: {  // 十神：每柱
      year:  { ganGod, hidden:[{gan, god, ratio}] },  // ganGod=天干十神, hidden=藏干及其十神+占比
      month: {...}, day: {...}, hour: {...}|null
    },
    shishenSummary: { counts:{正财:2,偏印:2,...}, text:"人生阶段说明" }
  },
  female: { /* 同 male 结构 */ },
  // —— 总分（复用现有算法）——
  score, hearts, level,
  // —— AI 分析（按需，可为空，点按钮才生成）——
  aiAnalysis: null | { dimensions:[...], advices:[...], highlight, score }  // 复用 V3 结构
}
```
- 十神「代表/表现特征」释义文案：后端用固定字典映射（十神名→{represent, trait}），不走 AI。
- 藏干占比 ratio：本气/中气/余气按惯例（本气100%或按位次给 70%/20%/10% 之类，参考图是「藏干 100%/70%/50%」这种档位，用约定档位即可）。
