## 一、产品基本信息

### 1.1 产品概况
- **产品名称：** 测测 / 测测星座
- **开发公司：** 北京力拓飞远科技有限公司
- **产品类型：** 泛心理在线社区 + 星座占卜工具
- **最新版本：** v10.30.0（2026年2月）
- **支持平台：** iOS / Android 双端
- **商业成绩：** 年营收破亿（媒体报道）

### 1.2 产品定位
测测是一个集合了多种测试和工具的泛心理在线社区，汇聚了心理、星座等领域的内容和服务。

**核心定位：**
- 星座爱好者的聚集地
- 情感问题解答平台
- 个人星盘分析工具
- 泛心理服务社区

## 二、核心功能模块

### 2.1 星座运势
**功能描述：**
- 每日运势、本周运势、一生运势
- 结合个人星图和宇宙星象推算
- 专属个性化运势播报

**特点：**
- 基于用户独一无二的个人星图
- 不是通用星座运势，而是个性化预测
- 运势分类：爱情、事业、财运、健康等

### 2.2 星盘工具
**功能描述：**
- 20种个人星盘工具
- 集成权威占星软件 astrolog 系列功能
- 支持查看各类星盘：返照盘、法达盘、太阳弧
- 二人合盘功能

**使用场景：**
- 输入个人信息（出生年月日时、地点）
- 生成高大上的个人星盘
- 深度解读星盘含义

### 2.3 塔罗占卜
**功能描述：**
- 塔罗牌在线测试
- 解答心中问题
- 在线解析情感困惑

**特点：**
- 多种塔罗牌阵
- 即时抽牌测试
- 专业解读

### 2.4 性格分析
**功能描述：**
- 基于星座的性格解读
- 12星座性格详解
- 星座起源故事

### 2.5 配对测试
**功能描述：**
- 星座配对指数
- 测算恋人之间的爱情指数
- 连线合盘功能

**特点：**
- 输入好友信息，轻轻一划
- 洞悉两人关系与缘分
- 依据精密算法推算神秘分数

### 2.6 情感咨询
**功能描述：**
- 星座塔罗师在线解答
- 情感问题咨询
- 匿名问答模块

**服务方式：**
- 文字咨询
- 语音解答
- 24小时在线

## 三、产品特色

### 3.1 "全"的策略
测测最大的特点就是"全"——东西方玄学大杂烩：

**传统派：**
- 生辰八字
- 紫微斗数
- 生肖
- 玛雅图腾

**西方派：**
- 星座
- 星盘
- 星宿
- 塔罗牌
- 星骰

### 3.2 个性化定制
- 不是通用的星座运势
- 基于用户独特的出生信息
- 结合实时宇宙星象
- 专属个人的预测结果

### 3.3 社区互动
- 千万星座爱好者聚集地
- 用户可以互相交流
- 分享测试结果
- 讨论星座话题

### 3.4 工具齐全
- 20种星盘工具
- 多种测算方式
- 丰富的测试内容
- 专业的解读服务
