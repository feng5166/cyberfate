## 三、需要设计的页面

### 3.1 首页入口卡片

**位置**: CyberFate 首页，功能卡片区

**内容**:
```
🐾 宠物人格卡
Pet Soul Card
发现你家毛孩子的隐藏灵魂
[生成卡片 →]
```

**要求**:
- 与其他功能卡片风格统一
- 图标使用 lucide 的 `PawPrint`
- 突出「有趣」和「新功能」的感觉

---

### 3.2 模块引导页 (/pet-soul)

**页面元素**:
1. 标题区: "Pet Soul Card" + "发现你家毛孩子的隐藏灵魂"
2. 插画区: **简约线条风格的猫狗并排图**（需要绘制）
3. 步骤说明: 📸 上传照片 → 📝 回答问题 → 🎴 生成档案
4. CTA 按钮: "✨ 开始生成"
5. 社会证明: "已有 12,345 只毛孩子获得了灵魂档案"

**插画要求**:
- 风格: 简约线条，赛博感
- 内容: 一只猫 + 一只狗并排（可以参考 Pet Soul Lab 但要有自己的风格）
- 颜色: 主色金色线条，深色背景
- 格式: SVG 或透明 PNG

---

### 3.3 信息输入页 (/pet-soul/create)

**页面元素**:
1. 进度指示: "1/4"
2. 照片上传区: 圆形区域，点击上传
3. 输入字段: 名字、类型、生日、性别
4. 物种选择: 8 个图标按钮（🐱🐶🐰🐹🐦🐢🐟🐾）
5. 下一步按钮

**参考线框图**:
```
┌─────────────┐
│             │
│  [上传照片]  │
│   📷 点击   │
└─────────────┘

宠物名字 *
┌───────────────────────┐
│  请输入宠物名字        │
└───────────────────────┘

宠物类型 *
┌────┐ ┌────┐ ┌────┐ ┌────┐
│🐱猫│ │🐶狗│ │🐰兔│ │🐹鼠│
└────┘ └────┘ └────┘ └────┘
```

---

### 3.4 趣味问题页 (/pet-soul/quiz)

**页面元素**:
1. 进度: "Question 1/3"
2. 问题文字: 如「豆豆在家是什么角色？」
3. 选项卡片: 4 个选项，每个带 emoji + 中英文

**选项卡片设计**:
```
┌─────────────────────────────────┐
│  👑  家里的老大                  │
│      The Boss                   │
└─────────────────────────────────┘
```

**要求**:
- 选项卡片要有 hover 和 selected 状态
- 点击后有微动效
- 每个选项可以有不同的渐变色调

---

### 3.5 生成中页面

**页面元素**:
1. 加载动画: 🔮 水晶球或类似元素
2. 进度条
3. 状态文字: "正在解析灵魂..." / "计算命盘中..."

**要求**:
- 动画要有神秘感
- 进度条带光效

---

### 3.6 结果卡片页 (/pet-soul/result) ⭐ 重点

**这是最重要的页面！**

**卡片结构**:
```
┌─────────────────────────────────────────────────┐
│  SOUL-2026-0319-001            [危险等级：S]    │
│                                                 │
│                 [宠物照片]                       │
│                 「豆 豆」                        │
│            辰时木猫 · 社交达喵型                  │
│                 ♓ 双鱼座                        │
│                                                 │
├─────────────────────────────────────────────────┤
│  粘人指数    ████████░░  80                    │
│  傲娇程度    ██████░░░░  55                    │
│  社交能力    █████████░  92                    │
│  好奇心      ███████░░░  68                    │
│  戏精天赋    ████░░░░░░  40                    │
├─────────────────────────────────────────────────┤
│  🔮 命理解读                                    │
│  「木命之猫，生于辰时，天生带有灵气...」         │
├─────────────────────────────────────────────────┤
│  💭 TA 的内心独白                               │
│  「又到饭点了，为什么还不来？...」               │
├─────────────────────────────────────────────────┤
│  [📤 分享]    [🔗 查看主宠缘分]                 │
│               CyberFate.ai                      │
└─────────────────────────────────────────────────┘
```

**设计要点**:
1. **档案编号**: 科技感字体，像实验室档案
2. **危险等级徽章**: S/A/B/C/D 不同颜色
3. **五维属性条**: 进度条设计，带光效
4. **卡片整体**: 有高级感，适合分享截图
5. **水印**: 底部 "CyberFate.ai"

**危险等级配色建议**:
- S: 红色/橙色（超级危险！可爱爆棚）
- A: 金色
- B: 蓝色
- C: 绿色
- D: 灰色
