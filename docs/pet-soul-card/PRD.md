## 一、模块概述

### 1.1 定位

CyberFate 的**娱乐化引流模块**，通过宠物命理分析吸引养宠用户群体，提升产品传播度。

### 1.2 一句话描述

> 用命理 + AI 的方式，为你的宠物生成一张专属灵魂档案卡

### 1.3 核心价值

| 价值维度 | 说明 |
|----------|------|
| 用户获取 | 养宠人群是巨大的垂直市场，易传播 |
| 品牌差异 | 市面同类产品无命理元素，形成差异 |
| 社交裂变 | 卡片天然适合分享，宠物 CP 配对促进传播 |
| 生态补充 | 与人的八字分析形成「主宠缘分」联动 |

---

## 二、用户场景

| 用户类型 | 场景 | 核心需求 |
|----------|------|----------|
| 新手铲屎官 | 刚养宠物 | 想了解毛孩子的性格 |
| 资深宠主 | 日常互动 | 找乐子 + 社交素材 |
| 多宠家庭 | 宠物相处 | 想知道毛孩子们合不合 |
| CyberFate 老用户 | 已用过八字 | 好奇主宠缘分 |

## 五、技术要点

### 5.1 API 设计

#### POST /api/pet-soul/create

**请求**:
```json
{
  "name": "豆豆",
  "species": "cat",
  "gender": "female",
  "birthDate": "2023-03-15",
  "imageUrl": "https://...",
  "answers": [1, 3, 2]
}
```

**响应**:
```json
{
  "id": "SOUL-2026-0319-001",
  "name": "豆豆",
  "species": "cat",
  "imageUrl": "https://...",
  "dangerLevel": "S",
  "zodiac": "双鱼座",
  "destinyType": "辰时木猫",
  "personalityType": "社交达喵型",
  "attributes": {
    "clingy": 80,
    "tsundere": 55,
    "social": 92,
    "curiosity": 68,
    "drama": 40
  },
  "destinyReading": "木命之猫，生于辰时...",
  "innerMonologue": "又到饭点了..."
}
```

#### POST /api/pet-soul/bond

**请求**:
```json
{
  "petSoulId": "SOUL-2026-0319-001",
```

**响应**:
```json
{
  "compatibility": 87,
  "title": "天作之合",
  "reading": "水命之人遇木命之猫...",
  "tips": [
    "每周二木旺之日，宜多互动",
    "周五金克木，注意 TA 的情绪波动"
  ]

```

### 5.2 AI Prompt 设计

**内心独白生成 Prompt**:

```
你是一个宠物心理专家。根据以下信息，用第一人称写一段宠物的内心独白：

宠物信息：
- 名字：{name}
- 类型：{species}
- 性格类型：{personalityType}
- 五维属性：粘人{clingy}，傲娇{tsundere}，社交{social}，好奇{curiosity}，戏精{drama}

要求：
1. 50-100字
2. 口语化，带有该性格特点
3. 有趣、可爱、让人会心一笑
4. 如果是高傲娇，要体现口是心非
5. 如果是高社交，要体现热情外向
```

### 5.3 图片处理

- 上传图片压缩至 500KB 以内
- 存储使用 CDN
- 卡片生成使用服务端渲染为图片（用于分享）
