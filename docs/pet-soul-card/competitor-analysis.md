# Pet Soul Lab 竞品分析

> 分析日期：2026-03-19
> 分析人：产品虾 🦐

## 产品概述

| 项目 | 内容 |
|------|------|
| 产品名 | Pet Soul Lab |
| Slogan | Discover Your Pet's Hidden Soul |
| 平台 | 移动端 App |
| 核心玩法 | 上传照片 + 回答问题 → AI 生成宠物灵魂档案 |

---

## 用户流程分析

### 完整流程（5步）

```
1/5 引导页 → 2/5 信息输入 → 3/5 问题回答 → 4/5 结果卡片 → 5/5 宠物匹配
```

### Step 1: 引导页

**设计特点：**
- 温暖柔和的紫粉色调
- 可爱插画风格（猫狗并排）
- 清晰的价值主张："Discover Your Pet's Hidden Soul"
- 简洁的流程说明："上传照片 → 回答问题 → AI 生成档案"

**CTA：** "✨ Start Now" 紫色圆角按钮

---

### Step 2: 信息输入页

**输入字段：**

| 字段 | 必填 | 说明 |
|------|------|------|
| 宠物头像 | ✅ | 支持上传照片 |
| Pet Name | ✅ | 宠物名字 |
| Species | ✅ | 物种选择 |
| Age | ❌ | 年龄（可选）|

**物种选项（8种）：**
- 🐱 Cat
- 🐶 Dog（带 AI 标签 - 自动识别）
- 🐟 Fish
- 🐰 Rabbit
- 🐹 Hamster
- 🐢 Turtle
- 🐦 Bird
- 🐾 Other

**亮点：**
- AI 自动识别物种（Dog 选项带 "AI" 标签）
- Emoji + 文字，视觉直观
- 流程简洁，必填项仅 2 个

---

### Step 3: 问题页

**问题数量：** 仅 3 个问题

**示例问题：** "Tino's role at home?"（宠物在家里的角色）

**选项设计：**
| 选项 | Emoji | 含义 |
|------|-------|------|
| Quiet Wallflower | 🪑 | 安静的小透明 |
| The Boss | 👑 | 家里的老大 |
| Loyal Sidekick | 🐾 | 忠诚的小跟班 |
| Silent Observer | 🔭 | 沉默的观察者 |

**设计亮点：**
- 问题口语化、有趣味性
- 用**性格标签**代替 A/B/C/D
- 每个选项不同配色，视觉区分清晰
- 问题数量极少（仅3个），降低流失

---

### Step 4: 结果卡片页 ⭐

**这是核心产出，设计极其精致！**

**卡片结构：**

```
┌─────────────────────────────────────┐
│ PET-2026-K312      [Danger Level A] │  ← 档案编号 + 危险等级
├─────────────────────────────────────┤
│           [宠物头像]                 │
│             Tino                    │
│      Type F · Social Butterfly      │  ← 人格类型
│            🐶 Dog                   │
├─────────────────────────────────────┤
│  Clingy    ████████░░  65          │
│  Ferocity  ███████░░░  60          │  ← 五维属性条
│  Social    █████████░  95          │
│  Curiosity ████████░░  75          │
│  Drama     █████░░░░░  50          │
├─────────────────────────────────────┤
│  💬 Inner Monologue                 │
│  "New friend! Another friend!       │  ← AI 生成的内心独白
│   Everyone is my friend! Hi, hello, │
│   did someone say hi?..."           │
└─────────────────────────────────────┘
```

**五维属性：**
| 属性 | 英文 | 说明 |
|------|------|------|
| 粘人度 | Clingy | 对主人的依赖程度 |
| 凶猛度 | Ferocity | 攻击性/防御性 |
| 社交力 | Social | 与人/其他宠物的互动 |
| 好奇心 | Curiosity | 探索欲望 |
| 戏精值 | Drama | 情绪表达/作精程度 |

**核心亮点：**
1. **档案编号** (PET-2026-K312) - 增加仪式感和收藏价值
2. **危险等级** (Danger Level A) - 趣味标签，适合分享
3. **人格类型** (Type F · Social Butterfly) - 类似 MBTI 的分类
4. **五维属性条** - 数据可视化，一目了然
5. **内心独白** - AI 生成的拟人化文案，情感共鸣点！

---

### Step 5: 宠物匹配页 ⭐⭐

**这是最大的亮点和传播点！**

**功能：** 两只宠物的 CP 配对

**展示内容：**
- 匹配度百分比（如 68%）
- CP 名称（如 "Chaos and Sunshine"）
- 关系描述文案
- **AI 生成的对话模拟** ← 神来之笔！

**对话示例：**

> **Tino (Social Butterfly):**
> "HIII! NEW FRIEND! I'm so happy to see you! Do you want to play? I know lots of games!"
>
> **Chaos Agent:**
> "Greetings, small energetic one. I am conducting structural integrity tests on this furniture. Would you like to observe? This cushion has FAILED."

**设计亮点：**
- 对话气泡设计，像真实聊天
- 每只宠物的语气完全不同，个性鲜明
- 文案有梗、有笑点，截图分享欲望强！

## 核心优势总结

1. **极简流程** - 仅 3 个问题，5 步完成
2. **AI 加持** - 自动识别物种 + 生成个性化文案
3. **情感共鸣** - 内心独白让用户觉得"就是我家毛孩子！"
4. **社交裂变** - CP 配对功能天然带传播属性
5. **视觉精致** - 温暖治愈的配色和插画风格
