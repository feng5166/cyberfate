## 一、V2 概述

### 1.1 V2 目标

在 MVP 基础上，扩展更多命理分析功能，满足不同用户群体的需求：
- **深度用户**: 紫微斗数、周易占卜等专业功能
- **年轻用户**: 塔罗牌等轻量化、社交化功能
- **情侣用户**: 八字合婚等关系分析功能

### 1.2 功能优先级

| 优先级 | 功能 | 理由 | 预计工期 |
|--------|------|------|----------|
| P0 | 塔罗牌 | 开发简单、传播性强、年轻用户喜欢 | 3-5天 |
| P1 | 八字合婚 | 刚需场景、付费意愿强、复用现有引擎 | 5-7天 |
| P2 | 紫微斗数 | 专业用户需求、技术复杂度高 | 10-14天 |
| P3 | 周易占卜 | 需要专业算法、用户群体相对小 | 7-10天 |
| P4 | AI 黄历 | 锦上添花、增加日活 | 3-5天 |

## 二、功能详细设计

### 2.1 塔罗牌 (/tarot)

#### 2.1.1 产品定位
轻量化、社交化的占卜工具，通过 AI 解读塔罗牌意，为用户提供心理疏导和决策参考。

#### 2.1.2 页面结构

**选择牌阵页**

牌阵选项：
1. **单张牌** - 快速指引
   - 适用场景：今日运势、快速决策
   - 抽牌数量：1张

2. **三张牌** - 过去现在未来
   - 适用场景：了解事情发展脉络
   - 牌位：过去 | 现在 | 未来

3. **凯尔特十字** - 深度分析
   - 适用场景：重大决策、深度探索
   - 牌位：10个位置（现状、挑战、根源、过去、目标、未来、自我、环境、希望/恐惧、结果）

**提问页**

输入框：
- 占位符："请输入你想问的问题（选填）"
- 说明文字："可以是关于感情、事业、学业等任何困扰你的问题"
- 字数限制：200字

**抽牌页**

交互流程：
1. 显示牌背（78张塔罗牌洗牌动画）
2. 用户点击选择对应数量的牌
3. 翻牌动画展示
4. 显示牌面和牌名

**解读页**

展示内容：
1. **牌面展示**
   - 牌面图片
   - 牌名（中英文）
   - 正位/逆位标识

2. **基础牌意**（固定内容）
   - 关键词（3-5个）
   - 牌意简述（50字）

3. **AI 个性化解读**（根据用户问题生成）
   - 针对问题的解读（150-200字）
   - 行动建议（50-100字）

4. **分享功能**
   - 生成精美卡片图片
   - 分享到社交媒体

#### 2.1.3 数据设计

**塔罗牌数据结构**

```json
{
  "id": 1,
  "name_en": "The Fool",
  "name_zh": "愚者",
  "suit": "major",
  "number": 0,
  "keywords": ["新开始", "冒险", "纯真"],
  "upright": "正位牌意描述",
  "reversed": "逆位牌意描述",
  "image_url": "/images/tarot/fool.jpg"
}
```

#### 2.1.4 API 设计

**POST /api/tarot/draw**

请求：
```json
{
  "spread": "single",
  "question": "我应该换工作吗？"
}
```

响应：
```json
{
  "spread": "single",
  "cards": [
    {
      "id": 1,
      "name_zh": "愚者",
      "orientation": "upright",
      "keywords": ["新开始", "冒险"],
      "image_url": "/images/tarot/fool.jpg"
    }
  ],
  "ai_reading": "AI 生成的个性化解读",
  "advice": "行动建议"
}
```

### 2.2 八字合婚 (/bazi/marriage)

#### 2.2.1 产品定位
为情侣、准夫妻提供八字合婚分析，评估双方匹配度，提供相处建议。

#### 2.2.2 页面结构

**输入页**

双方信息表单：

**男方信息**
- 姓名（选填）
- 出生日期（必填）
- 出生时间（选填）

**女方信息**
- 姓名（选填）
- 出生日期（必填）
- 出生时间（选填）

**结果页**

1. **匹配度总评**
```
综合匹配度: ❤️❤️❤️❤️☆ (80分)
```

2. **双方八字展示**
```
男方八字: 庚午 己卯 丙寅 壬辰
女方八字: 辛未 庚辰 丁卯 癸巳
```

3. **五行互补分析**
4. **性格匹配分析**（AI 生成）
5. **感情运势分析**（AI 生成）
6. **婚姻建议**（AI 生成）

#### 2.2.3 匹配度计算逻辑

**评分维度**（总分100分）

| 维度 | 权重 | 计算方法 |
|------|------|----------|
| 五行互补 | 30% | 五行相生相克关系评分 |
| 日主相合 | 25% | 日主天干地支合化关系 |
| 用神互补 | 20% | 双方用神是否互补 |
| 生肖相配 | 15% | 生肖六合、三合、相冲关系 |
| 纳音相生 | 10% | 年柱纳音五行相生关系 |

**匹配度等级**

| 分数 | 等级 | 描述 |
|------|------|------|
| 90-100 | 天作之合 ❤️❤️❤️❤️❤️ | 八字高度契合 |
| 80-89 | 良缘佳配 ❤️❤️❤️❤️☆ | 匹配度很高 |
| 70-79 | 相处融洽 ❤️❤️❤️☆☆ | 匹配度较好 |
| 60-69 | 需要磨合 ❤️❤️☆☆☆ | 需要互相理解 |
| <60 | 挑战较大 ❤️☆☆☆☆ | 需要更多包容 |

|------|----------|----------|

**命盘展示页**

```
│ 廉贞   │ 贪狼   │ 巨门   │ 天相   │
└────────┴────────┴────────┴────────┘
```

2. **十二宫详解**
- 命宫：性格特质
- 兄弟宫：手足关系
- 夫妻宫：婚姻感情
- 子女宫：子女缘分
- 财帛宫：财运状况
- 疾厄宫：健康状况
- 迁移宫：外出运势
- 奴仆宫：人际关系
- 官禄宫：事业发展

- 格局分析（150字）

4. **流年运势**（AI 生成）
- 今年整体运势

## 六、运营策略

### 6.1 功能上线顺序

**建议顺序：塔罗牌 → 八字合婚 → AI 黄历 → 紫微斗数 → 周易占卜**

**理由：**
1. 塔罗牌：快速上线，验证 AI 解读质量，吸引年轻用户
2. 八字合婚：刚需场景，提升付费转化
3. AI 黄历：增加日活，培养用户习惯
4. 紫微斗数：满足专业用户需求
5. 周易占卜：补充功能完整性

### 6.2 推广策略

**塔罗牌推广：**
- 社交媒体分享卡片（精美设计）
- 话题营销（#今日塔罗）
- KOL 合作

**八字合婚推广：**
- 情人节、七夕等节日营销
- 婚恋平台合作
- 情侣用户优惠
