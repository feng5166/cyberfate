## 一、任务概述

侧边栏底部根据用户登录/订阅状态显示不同内容。未登录显示两个转化按钮，已登录未订阅显示解锁按钮+用户信息，已登录已订阅保持现有行为。

**核心原则：按钮点击跳转页面（不使用弹窗 Modal）。**

## 二、涉及文件

| 文件 | 改动类型 | 说明 |
|------|---------|------|
| `src/components/layout/Sidebar.tsx` | **修改** | 底部区域改为三态渲染 |
| `src/app/page.tsx` (首页) | 检查 | 确认无登录入口（如有则移除） |
| `src/components/layout/Header.tsx` 或 Navbar | 检查 | 确认导航栏无登录入口（如有则移除） |

## 三、开发任务

### 任务：Sidebar 底部三态 UI

**目标**: Sidebar.tsx 底部区域根据 auth 状态渲染不同内容

**三种状态：**

#### 状态一：未登录（guest）

底部显示两个全宽按钮，上下排列，间距 gap-3：

**按钮 A — 解锁全部功能**
- 样式：`w-full py-3 px-4 bg-[#1C1A16] text-white rounded-xl text-sm font-medium hover:bg-[#2A2620]`
- 点击：`router.push('/pricing')`

**按钮 B — 登录 / 注册**
- 样式：`w-full py-3 px-4 bg-white text-[#1C1A16] border border-[#E5E7EB] rounded-xl text-sm font-medium hover:bg-[#F9FAFB]`
- 图标：左侧加 👤 或 User 图标（16px），与文字间距 gap-2
- 点击：`router.push('/auth/login')`

参考布局：
```
┌─ Sidebar 底部 ──────────────────────┐
│  ┌────────────────────────────────┐ │
│  │  🔓 解锁全部功能               │ │  ← 黑色实心
│  └────────────────────────────────┘ │
│  ┌────────────────────────────────┐ │
│  │  👤 登录 / 注册               │ │  ← 白底描边
│  └────────────────────────────────┘ │
└─────────────────────────────────────┘
```

#### 状态二：已登录 — 未订阅（free）

- 上方：「解锁全部功能」按钮（同状态一的按钮 A 样式）
- 下方：用户信息区（头像 + 昵称 + 邮箱），规格复用现有 7.1.8 节

```
┌─ Sidebar 底部 ──────────────────────┐
│  ┌────────────────────────────────┐ │
│  │  🔓 解锁全部功能               │ │
│  └────────────────────────────────┘ │
│         [头像 44px]                │
│         周峰                       │
│      zf@example.com               │
└─────────────────────────────────────┘
```

#### 状态三：已登录 — 已订阅（paid）

- 与现有 7.1.8 节"第六组：用户信息（底部固定）"**完全一致**
- 头像 + 昵称 + 邮箱 + 设置/退出链接
- 可加 VIP 小 Tag

### 首页改动

- 确认首页导航栏、Hero、Footer 无登录/注册按钮或链接
- 功能卡片可点击，点击后跳转目标路由
- 从首页跳转时目标页自动展开侧边栏（可通过 URL param 或全局状态触发）

### 状态判断逻辑

```typescript
// 在 Sidebar 组件内
const { user, isLoading } = useAuth()

// 底部区域渲染
const renderBottom = () => {
  if (!user) return <GuestBottom />          // 两按钮
  if (!user.isSubscribed) return <FreeBottom /> // 解锁按钮 + 用户信息
  return <UserBottom />                        // 现有用户区（VIP）
}
```

## 四、验收标准

- [ ] 未登录 → 侧边栏底部两按钮（黑"解锁全部功能" + 白"登录/注册"）
- [ ] 点「解锁全部功能」→ 跳转 `/pricing`
- [ ] 点「登录 / 注册」→ 跳转 `/auth/login`
- [ ] 已登录未订阅 → 「解锁全部功能」按钮 + 头像/昵称/邮箱
- [ ] 已登录已订阅 → 用户信息 + VIP（与现有一致）
- [ ] 首页无任何登录入口
- [ ] 首页点功能卡片 → 跳转 + 侧边栏展开
- [ ] 移动端 Drawer 适配（两按钮在 Drawer 底部同样展示）
- [ ] 三种状态切换流畅，无闪烁

## 五、通用要求

1. Design Tokens v6：遵循第六章设计规范
2. 禁止纯黑底选中态：边框高亮 + 极淡暖底填充
3. TypeScript 全强类型
4. 响应式：桌面端 Sidebar + 移动端 Drawer 都要适配
