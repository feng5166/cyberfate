# 测测 App 体验研究清单

## 📱 第一步：下载与首次体验

### 新手引导
- [ ] 打开 app 后的第一屏是什么？
- [ ] 是否需要注册/登录？流程如何？
- [ ] 新手引导有几步？引导什么内容？
- [ ] 是否要求输入生辰八字/星座信息？
- [ ] **截图：** 启动页、引导流程、注册页面

### 首页结构
- [ ] 首页有哪些核心模块？（导航、推荐、运势等）
- [ ] 信息架构是什么？（tab 结构 or 单页滚动）
- [ ] 首屏推荐什么内容？
- [ ] **截图：** 首页全貌、各个 tab

## 🎯 第二步：核心功能拆解

### 1. 星座/运势功能
- [ ] 每日运势在哪里？展示什么内容？
- [ ] 是否有周运势、月运势、年运势？
- [ ] 运势内容的颗粒度（爱情、事业、财运、健康等）
- [ ] 是否有运势提醒/推送？
- [ ] **截图：** 各类运势页面

### 2. 测算/占卜功能
- [ ] 有哪些测算类型？（塔罗、八字、紫微斗数、姓名等）
- [ ] 测算流程是怎样的？（输入信息 → 计算 → 结果）
- [ ] 免费 vs 付费测算的区别？
- [ ] 测算结果的呈现方式（文字、图表、视频？）
- [ ] **截图：** 测算列表、测算流程、结果页面

### 3. 社区/内容功能
- [ ] 是否有社区/广场？
- [ ] 用户可以发布什么内容？
- [ ] 内容推荐算法（热门、关注、推荐）
- [ ] 是否有 KOL/大师入驻？
- [ ] **截图：** 社区首页、内容详情页

### 4. 咨询/问答功能
- [ ] 是否可以向大师提问？
- [ ] 咨询是文字、语音还是视频？
- [ ] 咨询如何收费？
- [ ] 大师的展示方式（头像、简介、评价、价格）
- [ ] **截图：** 大师列表、咨询页面
