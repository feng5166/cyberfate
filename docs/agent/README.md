## 一句话

把 cyberfate 从**工具型**(选模块 → 出报告 → 走人)升级为**陪伴型**——一个**从第一天就懂你、并陪你越来越懂你的 AI 知己「小满」**,用"记得你"建立粘性与数据壁垒。

## 核心定位

- **不做"AI 命理师",做"懂你的本命知己"**:用命盘解决陪伴 AI 最痛的"冷启动不够懂你",用记忆把一次性工具变成越养越深的关系。
- **合规先行**:定位为自我觉察 / 情绪陪伴 / 传统文化娱乐;命盘是"了解自己的镜子",不是预言;规避"算命/预测/改运"。
- **slogan 方向**:每个人,都值得一个真正懂你的人。

## 已锁定的关键决策

| 维度 | 选择 |
|---|---|
| 人设 | 单一温暖知己「小满」(寓意"将满未满,丰盈而留余地",合规友好) |
| P1 范围 | 极简验证——只赌一个假设:**"它记得我"能否把人留下来** |
| P1 做 | 命名 + 持久记忆 + 文字深聊 + 命盘接地(复用现有工具链) |
| P1 不做 | 每日打卡 / 主动 push / 事件回访 / 语音 / 多人设 / 年度之书 |
| 记忆抽取 | 每轮异步 + 纯 LLM(看到同实体已有记忆以判 new/update/close) |
| 记忆检索 | P1 不上向量(破 ~50 条再上 pgvector),分层组装 + recency |
| 记忆可删 | P1 后端支持删除,前端"小满记得的我"管理页放 P2 |
| 北极星 | Agent 用户的 D7/D30 留存 & 周复访率 |

## 三个关键设计洞察

1. **陪伴记忆 ≠ RAG**:核心是"存得对、更新及时、引用自然";难在人会变化(thread 有生命周期、会作废),不能只追加。
2. **命盘 = 冷启动护城河**:别家陪伴 AI 第一天啥都不懂,小满天生有一份"结构化的你"(命格/十神/神煞/大运/流年)。
3. **引用安全 = 信任命门**:对进行中的事用问句 + hedge,防"拿过期/错的事当现在"翻车。
