## 一、背景与目标

### 1.1 背景

当前每日运势页面（/daily）只提供"日"级别的运势查询，用户无法理解当日运势处于哪个命理周期之中。竞品已普遍提供大运/流年/流月三层时间轴，帮助用户建立完整的命运坐标系。

核心问题：用户看到今日运势是"吉"，但不知道是在大运走好时期的顺势之吉，还是逆势之中的昙花一现——缺乏上下文，判断价值打折。

### 1.2 目标

在每日运势页面的日期选择器上方，新增一个"运势全景"模块，展示三层命理时间轴：大运（10年）、流年（1年）、流月（1个月）。

**成功指标**：
- 页面停留时间提升 20%（用户在时间轴上有更多探索行为）
- 时间轴区域点击率 > 15%
- 用户对"运势解读深度"的满意度评分提升

### 1.3 边界

- 本期只做展示，不做可点击跳转详情页
- 本期不做大运/流年的独立分析页
- 本期不做流日（天干地支日历）的完整月历展示

## 二、命理基础说明（开发必读）

### 2.1 三层时间轴定义

| 层级 | 周期 | 定义 | 典型信息 |
|------|------|------|----------|
| 大运 | 10年一柱 | 由出生八字推算，每10年换一个干支，从童年一直排到老年 | 第N运、干支（如丙辰）、年龄区间、年份区间、十神 |
| 流年 | 1年一柱 | 即该自然年的年柱干支（太岁），与命局形成当年整体格局 | 年份、干支（如丙午）、年龄、十神 |
| 流月 | 1个月一柱 | 以节气为界（非公历月份），与流年配合影响当月运势 | 节气名、干支、日期区间（节气起止）、十神 |

### 2.2 十神说明

十神是日主（出生日干）与其他干支的关系，共10种：
正官、七煞（偏官）、正印、偏印（枭神）、比肩、劫财、食神、伤官、正财、偏财

计算方法：固定逻辑，根据日主（天干）与目标天干的五行生克关系 + 阴阳关系确定。

### 2.3 大运起运规则

- 阳年生男/阴年生女 → 顺数（生日起向后数到下一个节气）
- 阴年生男/阳年生女 → 逆数（生日起向前数到上一个节气）
- 每3天 = 1年起运
- 起运年龄确定后，往后每10年换一柱

### 2.4 流月节气边界

流月以节气为界，不是公历月份的1号：
- 正月：立春
- 二月：惊蛰
- 三月：清明
- 四月：立夏
- 五月：芒种
- 六月：小暑
- 七月：立秋
- 八月：白露
- 九月：寒露
- 十月：立冬
- 十一月：大雪
- 十二月：小寒

## 三、功能描述

### 3.1 模块位置

在 `/daily` 页面：

```
[页面头部 - 每日运势标题]
        ↓
[运势全景模块] ← 新增
        ↓
[周视图日期选择器]（现有）
        ↓
[今日运势结果]（现有）
```

### 3.2 运势全景模块结构

```
┌─────────────────────────────────────────────┐
│  运势全景                                    │
│  从大运、流年、流月全面把握运势节奏           │
│                                             │
│  大运  ────────────────────────  • 当前大运  │
│  [丙午] [丁未] [戊申 ●] [己酉] [庚戌]       │
│  横向可滚动                                  │
│                                             │
│  流年  ────────────────────────  • 当前年份  │
│  [甲辰] [乙巳] [丙午 ●] [丁未] [戊申]       │
│                                             │
│  流月  ────────────────────────  • 当前月份  │
│  [壬辰] [癸巳] [甲午 ●] [乙未] [丙申]       │
│                                             │
└─────────────────────────────────────────────┘
```

### 3.3 每行卡片字段

**大运卡片（每张）**：
```
第N运          ← 小标签，灰色
丙 午          ← 干支，大字，天干地支分行或并排
23–32岁        ← 年龄区间
2003–2012      ← 年份区间
正官            ← 十神，带颜色标签
贵人助力        ← 十神注释，10px灰色小字（Frank 拍板：做差异化）
```

**流年卡片（每张）**：
```
2026           ← 年份，大字
丙 午          ← 干支
43岁           ← 年龄
正官            ← 十神
贵人助力        ← 十神注释，10px灰色小字
```

**流月卡片（每张）**：
```
小满           ← 节气名，大字
癸 巳          ← 干支
05/21–06/05    ← 节气起止日期
食神            ← 十神
才华展现        ← 十神注释，10px灰色小字
```

### 3.4 高亮规则

- 大运：高亮用户当前所处的那一柱
- 流年：高亮当前年份
- 流月：高亮当前节气月

高亮样式：
- 外层容器：深色边框（`border-[#1C1A16]`） + 极淡暖底填充（`bg-[#FAF8F4]`）
- 十神标签：深色背景 + 白字
- 当前标记：右上角显示「• 当前大运 / • 当前年份 / • 当前月份」红点标记

非高亮卡片：白色背景，浅灰边框，较低文字对比度

### 3.5 横向滚动行为

- 三行均支持横向滚动（overflow-x: scroll，隐藏滚动条但保留滑动）
- 默认滚动到当前高亮卡片可见位置（居中或靠左一格）
- 大运默认展示：当前大运左右各2柱，共5柱可见（滚动可查看全部，Frank 拍板）
- 流年默认展示：当前年份左右各2年，共5年可见
- 流月默认展示：当前月份左右各2个节气月，共5个可见
- 移动端三行均直接显示，不折叠收起（Frank 拍板）

### 3.6 前置条件

- 用户有出生数据（birthDate + birthHour）才显示此模块
- 未填写出生数据时，此模块显示"填写出生信息后查看完整命理脉络"占位提示
- 加载中状态：显示骨架屏（三行卡片轮廓）

### 4.2 缓存策略

- 大运数据：一旦计算不变，用户维度缓存（Redis，key: `timeline:${birthDate}:${birthHour}:${gender}`）
- 流年数据：按年缓存，一年内不变
- 流月数据：按节气月缓存，节气换月时更新

## 五、UI 规格

### 5.1 设计Token（沿用现有规范）

| Token | 值 | 用途 |
|-------|----|------|
| 高亮边框 | `#1C1A16` | 当前卡片边框 |
| 高亮背景 | `#FAF8F4` | 当前卡片底色 |
| 普通边框 | `#E5E7EB` | 非当前卡片边框 |
| 普通背景 | `#FFFFFF` | 非当前卡片背景 |
| 红点标记 | `#DC2626` | 当前标记圆点 |
| 十神标签背景（当前） | `#1C1A16` | 当前卡片十神标签 |
| 十神标签背景（普通） | `#F3F4F6` | 非当前卡片十神标签 |

### 5.2 卡片尺寸

| 类型 | 宽度 | 高度 |
|------|------|------|
| 大运卡片 | 120px | 100px |
| 流年卡片 | 90px | 90px |
| 流月卡片 | 110px | 90px |

卡片圆角：`rounded-xl`（12px）
卡片间距：`gap-2`（8px）

### 5.3 干支字体

- 天干+地支并排显示，用空格分隔
- 字号：`text-xl`（20px），`font-semibold`
- 使用衬线字体：`font-serif`（Cormorant Garamond / Noto Serif SC）

### 5.4 骨架屏

加载中时展示三行各5个卡片轮廓，用 `animate-pulse bg-gray-100` 实现。

## 六、交互细节

### 6.1 无数据状态

用户未填写出生信息时：

```
┌─────────────────────────────────────────────┐
│  运势全景                                    │
│  ┌───────────────────────────────────────┐  │
│  │  📅 填写出生信息后查看完整命理脉络      │  │
│  │  大运、流年、流月将为您完整呈现         │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

### 6.2 数据加载失败

显示："命理脉络加载失败，请刷新重试"，不影响下方每日运势功能。

### 6.3 本期不做的交互

- 点击大运卡片跳转详情（本期不做）
- 悬停展示 tooltip 详解（本期不做）
- 手动切换大运起运年（本期不做）

## 七、验收标准

| 编号 | 验收项 | 标准 |
|------|--------|------|
| AC-1 | 三层时间轴正确显示 | 大运/流年/流月各自高亮当前柱，数据与命理计算吻合 |

| AC-6 | 响应式 | 移动端（375px）正常显示，卡片宽度适当缩减 |
| AC-7 | 字体显示 | 干支使用衬线字体，与页面整体风格一致 |
| AC-8 | 当前高亮样式 | 高亮卡片边框+背景+十神标签均正确，禁止纯黑底 |
