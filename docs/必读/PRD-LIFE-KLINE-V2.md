# 人生K线 V2 · 产品需求文档

> 基线:2026-07-31 main 分支现状(V1 已上线:`/life-kline`,确定性百年 OHLC K线 + 概览统计 + VIP AI 问答 + 导出 PNG)。
> V2 主题:**把一张一次性的图,变成一段有信任、能传播、会回访、可变现的关系。**
> 配套阅读:`PRD-MODULES-DETAILED.md`(模块基线格式)、`DESIGN-SYSTEM.md`(视觉规范,所有新 UI 必须遵守)。

---

## 1. 背景与诊断

V1 的引擎是被低估的资产:纯确定性排盘计分(用神/忌神 + 十神 + 刑冲会合 + 岁运并临),零 AI 成本、免登录可用、结果可复现可解释。但产品形态存在四个结构性问题:

| # | 问题 | 后果 |
|---|------|------|
| D1 | 百年曲线信息过载,过去与未来平铺,浪费了"可验证区间"的信任价值 | 用户不信 → 不看未来 → 不付费 |
| D2 | 只有总运单线;命理上同一年可"利财不利婚",单分无法表达 | 缺最自然的付费点 |
| D3 | 导出 PNG 是整卡截图,信息密、无炫耀点、无回流入口 | 传播系数低 |
| D4 | 一次性工具,无任何回访理由 | 留存 ≈ 0 |
| D5 | high/low 影线由伪随机振幅生成,无命理含义,懂行用户追问答不上 | 专业信誉风险 |

## 2. 目标与非目标

**目标**(按优先序):
1. **信任**:用"回测过去"复刻线下命理师"先断过去再言未来"的信任构建铁律。
2. **传播**:专用分享卡 + 合盘对比,把 K线图变成社交货币。
3. **变现**:分维度曲线(财/事业/感情/健康)作为核心付费点;AI 问答入口场景化前移。
4. **留存**:流月下钻、换运倒计时、新流年报告,给用户回来的理由。

**非目标**:
- 不改总运评分算法主体(V1 的 `scoreFlow` 保持兼容,分维度是在其上分桶,不是重写)。
- 不做真人命理师服务、不做付费"化解/法事"类目(合规红线,见 §8)。
- V2 不做 App push 通道选型(页面内倒计时先行,push 列为 V2.1)。

**北极星指标**:分享卡导出率(生成结果 → 导出分享卡)。护栏指标:回测"准"投票占比 ≥ 55%(低于此值说明评分权重需调,先修引擎再推传播)。

## 3. 功能设计

### P0-A 过去回测「这一年,你过得怎么样?」

**用户故事**:作为首次生成K线的用户,系统先指着我经历过的某个大起/大落年份问我"这年是不是这样",我点了"准",才愿意相信它对未来的判断。

**交互**:
- 生成结果后、K线图上方插入「回测卡」:从区间 `[max(18岁, 起运年), 当前年-1]` 内选**收盘分最高 1 年 + 最低 1 年**(若用户虚岁 < 20 则跳过整个模块)。
- 每年一张小卡:年份/岁数/干支 + 等级徽章 + 一句话短评(复用 `point.comment`),下方两个按钮「准 ✓」「不准 ✗」。
- 投票后卡片翻转显示该年命理依据(`interactionsBrief` 白话化,如"冲日支 · 岁运并临"→"这一年流年冲动你的婚姻宫,又逢换运,变动剧烈"),并出现引导:「想知道未来哪几年是这种级别的年份?→ 查看未来关键年」(锚点滚动到K线未来区间高亮)。
- 两张卡都投完(或跳过)后回测卡收起为一行摘要。

**计算逻辑**:纯前端从 `result.points` 筛选,无新 API。极值年若相邻(±2 年内)则低分年取次低,保证两卡年份拉开。

**数据**:投票落库 `KlineBacktestVote`(userId/匿名指纹、birthHash、year、score、vote、createdAt),用于:① 护栏指标监控;② 后续按十神/刑冲类型分组分析哪类判断最不准,反哺 `TEN_GOD_SCORE`/`RELATION_EFFECT` 权重调优。未登录用户仅打埋点不落库。

**埋点**:`kline_backtest_show` / `kline_backtest_vote {vote: 'yes'|'no', level, year_offset}` / `kline_backtest_skip`。

**门槛**:免费,所有人可用(这是信任漏斗入口,不设墙)。

---

### P0-B 分享卡(替代裸导出)

**用户故事**:作为觉得结果有趣的用户,我想发一张好看、别人看得懂、带点炫耀感的卡到朋友圈/群里。

**交互**:
- 现有「导出」按钮改为「分享」,弹出分享卡预览(3:4 竖版,适配朋友圈/小红书),提供「保存图片」。原整卡截图导出保留为次级入口「导出完整图」。
- 分享卡内容(自上而下):
  1. 一句话人设标题,从 summary 派生模板,如:**「我的人生巅峰在 2034 年(38 岁)」** / 巅峰已过者用「我的黄金十年是 45-54 岁,现在正在半山腰」(模板须保证任何命盘都有正向表述可选,见 §8 表述规范)。
  2. 百年曲线缩略图(仅收盘线 + MA10,不画蜡烛,降低理解门槛;当前年打点标注)。
  3. 三个数据点:最佳十年 / 当前阶段 / 下一个上升期起点。
  4. 品牌落款 + 二维码(`/life-kline?ref=share`)+ 免责一行小字。
- 生成方式:专用隐藏 DOM 节点 + 现有 `html-to-image` 方案,复用 V1 依赖,不引入 canvas 库。

**埋点**:`share_card_open` / `share_card_export`(区别于现有 `share_export`)/ 落地页 `ref=share` 归因进现有 analytics。

**门槛**:免费。分享卡是获客资产,不设墙。

---

### P1-A 分维度K线:财运 / 事业 / 感情 / 健康(核心付费点)

**用户故事**:作为对总运图产生信任的用户,我想知道"明年到底是利财还是利事业",并愿意为此付费。

**命理映射**(在 `scoreFlow` 内按十神类别分桶,总分算法不变,新增副产物):

| 维度 | 计分来源 |
|------|----------|
| 财运 | 正财/偏财十神分 + 食伤生财链(食神/伤官在用神侧时半权重计入)+ 财星所在支被刑冲的扣分 |
| 事业 | 正官/七杀 + 正印/偏印十神分 + 官杀与日主强弱取向 |
| 感情 | 配偶星(男命财星/女命官杀)得力度 + 日支(婚姻宫)刑冲会合专项(日支冲/合在此维度权重 ×2)+ 桃花神煞 |
| 健康 | 忌神克身强度 + 刑冲总 volatility 折算 + 凶煞(病符类)专项 |

各维度独立走缓动与 clamp,输出 `points[i].dims: { wealth, career, love, health }`(仅收盘线,不做四套 OHLC,避免过度演绎)。

**交互**:K线图例区新增五个 toggle:总运(默认)/ 财 / 业 / 情 / 健。非 VIP 点击维度线 → 弹半透明模糊预览 + 订阅引导(「解锁四维运势曲线」)。VIP 可多选叠加(最多总运 + 2 条,防止视觉糊)。hover 提示卡同步显示当前所选维度分。

**API**:`/api/life-kline` 响应默认不含 `dims`;请求带 `withDims: true` 且服务端校验 VIP 后返回。**金额与权益一律服务端校验,不信任前端**(项目既有规范)。

**埋点**:`kline_dim_switch {dim}` / `kline_dim_paywall_show` / `kline_dim_paywall_click`。这是订阅转化主漏斗,paywall 曝光→点击→支付逐级归因。

**门槛**:**VIP(专业版及以上)**。与合婚的付费定位对齐。

---

### P1-B 流月下钻 + 影线归真

**用户故事**:作为 VIP 用户,我点某一年,想看到这一年 12 个月哪个月该进、哪个月该守。

**计算逻辑**:
- 新增 `src/lib/bazi/liuyue.ts`:按节令起月干支(`lunar-javascript` 提供),逐月对命局 + 当年流年做与 `scoreFlow` 同构的简化计分(月干支五行对用神 + 与命局/流年支刑冲,不计神煞)。
- **影线归真(修复 D5)**:年K线的 `high` 改取当年 12 流月分最高值、`low` 取最低值(替代伪随机振幅)。伪随机仅保留用于无月度差异时的 ±1 微扰。此后每根影线可解释:"上影 82 = 你当年最好的月份(酉月)能到的高度"。hover 提示卡增加「最佳月/最差月」。

**交互**:点击某根年K线 → 底部抽屉展开该年 12 根月K线(同款图,x 轴为节令月),每月一句短评 + 宜/忌标签。年份抽屉内嵌 AI 问答快捷入口(预设问题:"我 {year} 年 {best_month} 前后要注意什么?")。

**门槛**:**VIP**。非 VIP 点击年K线弹模糊预览 + 订阅引导。

**埋点**:`kline_month_drill {year, is_vip}` / `kline_month_paywall_show`。

---

### P1-C 场景化 AI 入口 + 低谷年给出路

**用户故事**:作为看到自己某年是「低谷」的用户,我不想只被告知"宜蓄势待时",我想知道具体该怎么办。

**设计**:
- hover/点击「低谷」「承压」年份时,提示卡尾部追加一行建议 + 入口:「这一年宜 {从用神派生:进修/储蓄/随军远行…},忌 {从忌神/刑冲派生:跳槽创业/大额投资/合伙}。想展开?→ 问 AI 命理师」,点击直接把该年上下文注入 `BaziChatSection` 并滚动聚焦,预填问题"我 {year} 年({ganzhi} 年)运势承压,具体该怎么安排?"。
- 「极盛」「上佳」年份对称处理("这一年宜进取:{建议},抓住 {best_month}")。
- 宜/忌建议为**本地模板**(用神五行 × 十神 → 建议词库,新增 `src/lib/bazi/adviceTemplates.ts`),零 AI 成本;AI 只在用户主动追问时介入(现有 VIP 门禁不变)。
- **表述规范(命理伦理)**:低谷年措辞一律"提醒蓄力"框架,禁止恐吓词(灾/劫/血光/破败);禁止由低谷引导购买任何"化解"类商品。详见 §8。

**埋点**:`kline_advice_show {level}` / `kline_advice_to_chat {level}`(预计成为 AI 问答第一大入口,替代现在的页尾入口)。

**门槛**:宜忌一句话免费;AI 追问走现有 VIP 门禁。

---

### P2-A 叙事化「人生剧本」

**用户故事**:作为普通用户,"运势分 61"对我没有意义,我想读到一段关于我自己的故事。

**设计**:概览卡上方新增一段 3-4 句的模板化叙事(零 AI 成本),结构固定:
1. 先天底色:「{日主}命,{格局},喜{用神}」白话一句。
2. 已走过的:「你人生的第一个高峰出现在 {过去峰值年},那年 {comment}」(虚岁 < 25 则改述童限/求学段)。
3. 正在经历的:「现在你走在 {currentPhase},本步 {大运干支} 大运还剩 {n} 年」。
4. 即将到来的:「下一个十年级别的上坡从 {下个高于当前 MA10 的年份} 开始」。

模板拼接自现有 `summary`/`meta`/`points`,新增 `buildNarrative()` 纯函数,放 `src/lib/bazi/lifeKline.ts` 同层。

**门槛**:免费。

---

### P2-B 换大运倒计时(回访钩子第一步)

**设计**:命盘信息条的「当前大运」卡升级:进度条(本步大运已走 n/10 年)+ 倒计时「距换 {下步干支} 大运还有 {n} 天」+ 下步大运一句话预告(`describeDayun` 已有产物)。跨流年时(北京时间新年立春后首次访问)顶部横幅「你的 {新年干支} 流年报告已更新」。

登录用户可点「换运时提醒我」→ V2 仅落库意向(`KlineRemindIntent`),通道(邮件/push)在 V2.1 选型后触达。按钮文案明示"上线后第一时间通知你",不承诺即时性。

**门槛**:免费(登录)。**埋点**:`kline_remind_subscribe`。

---

### P2-C 合盘对比(裂变形态)

**用户故事**:作为用户,我想把我和朋友/伴侣的曲线叠在一张图上,看"谁先发达""我们什么时候同频"。

**设计**:
- `/life-kline/compare`:双人出生信息输入(A 默认带入本人已存信息)→ 同图叠加两条收盘线(A 主色/B 对比色,不画蜡烛)→ 统计条:同频指数(两线年度涨跌方向一致率)、"你们最同步的十年"、"运势交叉年"(两线相交的年份列表)。
- 专属分享卡(双人版,3:4):「我们的运势在 {year} 年交汇」。
- 计算零成本:前端调两次现有 `/api/life-kline` 即可,无新算法;guest 限流沿用现有 20 次/时。

**门槛**:曲线叠加 + 同频指数免费(裂变入口);双人深度解读引导至合婚模块(付费,承接现有商业化)。

**埋点**:`kline_compare_generate` / `kline_compare_share`。

## 4. 商业化与门槛总表

| 能力 | 免费 | VIP(专业版+) |
|------|------|------|
| 百年总运K线 / 概览 / 回测 / 叙事 / 倒计时 | ✓ | ✓ |
| 分享卡 / 合盘叠加 | ✓ | ✓ |
| 分维度曲线(财/业/情/健) | 模糊预览 | ✓ |
| 流月下钻 + 影线月度归因 | 模糊预览 | ✓ |
| AI 问答(含场景化入口) | 引导订阅 | ✓ |
| 合盘深度解读 | → 合婚模块付费 | 按合婚权益 |

原则:**信任与传播链路(回测/分享/合盘叠加)永远免费;深度与颗粒度(维度/月度/AI)付费。**

## 6. 里程碑

| 阶段 | 内容 | 验收口径 |
|------|------|----------|
| M1(信任+传播) | P0-A 回测、P0-B 分享卡 | 回测投票率 ≥ 40%,"准"占比 ≥ 55%;分享卡导出率基线建立 |
| M2(变现) | P1-A 分维度、P1-C 场景化入口、P2-A 叙事 | 维度 paywall 曝光→订阅转化率 vs 现有页尾入口对比 |
| M3(留存+裂变) | P1-B 流月下钻、P2-B 倒计时、P2-C 合盘 | 7 日回访率、合盘发起量、`ref=share` 新客占比 |

M1 不依赖任何新算法,纯前端 + 一张投票表,先行验证方向;M2 动引擎,需过全量测试;M3 中影线归真依赖 P1-B 流月引擎,故下钻与归真同期。

## 7. 衡量指标

- **北极星**:分享卡导出率(结果生成 → `share_card_export`)。
- 信任:回测投票参与率、"准"占比(护栏 ≥ 55%,连续两周低于则冻结传播推广、回调评分权重)。
- 变现:`kline_dim_paywall_show → 订阅支付` 转化率;`kline_advice_to_chat` 占 AI 问答入口比例。
- 留存:生成用户 7 日回访率;`kline_remind_subscribe` 订阅数。
- 裂变:`ref=share` / 合盘落地新客占比。

## 8. 风险与表述规范(命理伦理红线)

1. **不恐吓**:低谷/承压年禁用灾祸类词汇,一律"提醒-蓄力-给建议"三段式;分享卡标题模板只从正向池选取,任何命盘都必须存在可用的正向表述(峰值在过去 → 强调黄金十年;整体平缓 → 强调"稳"的叙事)。
2. **不收割焦虑**:禁止由低谷年引导购买"化解/开光/法事"类目;付费解锁的是"更细颗粒度的信息",不是"免除厄运"。
3. **免责一致性**:分享卡、合盘卡、月度抽屉均需带既有免责句式("仅供参考与娱乐,人生走向取决于个人选择与努力")。
4. **回测反噬风险**:若"准"占比长期偏低,回测会反向摧毁信任 —— 故 M1 灰度发布(10% 流量)先看数据,达护栏再全量;这也是把 M1 排最前的原因之一。
5. **合盘隐私**:B 方出生信息不落库、不写入本人 `saveBirthInfo`,仅当次计算。
