# PRD - 每日运势页结果显示迭代 V1

> 作者：产品虾 | 日期：2026-06-01 | 状态：待开发
> 触发：Frank 拿 FateMaster 每日运势页对比 CyberFate /daily 页，要求优化迭代
> 决策：Frank 已确认「全部安排迭代」

## 一、背景与定位

对标竞品 FateMaster 是「极简可执行日历内页」，信息少但每条落地。
CyberFate /daily 是「轻命理报告」，专业纵深更强（五行强弱 / 大运流年 / AI 综合分析）。

**定位结论：不向 FateMaster 的极简退，而是把「丰富」做出层次。**
核心三件事：去重复、补内容、把专业数据翻译成人话。

## 二、问题诊断（基于真实代码，非截图臆测）

涉及文件：
- 前端：`src/app/daily/PageClient.tsx`
- 后端 prompt：`src/lib/ai/prompts.ts`（DAILY_SYSTEM_PROMPT）
- 后端接口：`src/app/api/daily/route.ts`

| # | 问题 | 根因（代码定位） | 优先级 |
|---|------|----------------|--------|
| 1 | 顶部断语与底部今日指引一字不差重复 | 顶部「一句话解读」用 `result.advice.slice(0,50)`，底部「今日指引」用完整 `result.advice` —— 同一字段双用，前 50 字必然重复 | P0 |
| 2 | 宜忌偏少且「·」连写丢失清单感 | prompt 限定 `suitable 固定3条 / avoid 固定2条`；前端用 reduce 每 2 条拼成一行 `pair.join(' · ')` | P0 |
| 3 | 「数据来源: cache」暴露技术调试信息给用户 | 前端直接渲染 `result._source` | P0 |
| 4 | 五行卡片过高、缺人话解读，喧宾夺主 | `minHeight:88`，只显示「火/旺」无解读，普通用户看不懂含义 | P1 |
| 5 | 幸运信息插在断语与宜忌之间，打断阅读流 | 幸运信息条嵌在顶部白卡内 | P1 |
| 6 | 断语文案偏抽象 | prompt `advice 限40字`，定位模糊既要定调又要给建议 | P1 |

## 三、迭代方案

### P0-1 断语与今日指引去重（数据层 + 前端层）

**后端（prompts.ts DAILY_SYSTEM_PROMPT + 示例 + route.ts 降级模板 + 前端 DailyResult interface）：**
新增独立字段 `briefing`：
- 职责：顶部「断语/定调」，~20-28 字，给今日整体氛围 + 一个具体利好或风险，可含命理术语。
- 与 `advice` 区分：`advice` 保持完整「行动建议」（底部今日指引用），不再被顶部截取。

prompt 输出规则补充：
- `briefing`：20-28字，今日定调，前半句给具体利好/风险，后半句给应对基调，可含命理术语。
- `advice`：放宽到 40-70字，纯行动建议，不与 briefing 重复、不重复 suitable/avoid。

示例补充 `briefing` 字段，如：「今日财旺身弱，偏财有机但易疲惫，宜守不宜攻。」

**前端：**
- 顶部「一句话解读」：`result.briefing`（无则降级 `result.advice.slice(0,50)` 兼容旧缓存）。
- 底部「今日指引」：保持 `result.verse`（金句）+ `result.advice`（完整建议），不变。

### P0-2 宜忌补齐 + 竖排独立成行

**后端 prompt：**
- `suitable` 固定 5 条（原 3 条），每条 5-8 字，动宾具象短语。
- `avoid` 固定 5 条（原 2 条），每条 5-8 字。
- route.ts 降级生成同步：suitable/avoid 池补足并固定输出 5 条。

**前端：**
- 删除 reduce 两两拼行逻辑，改为 `result.suitable.map` 每条独立一行（忌同理）。
- 行间距保持 lineHeight 2.0 的呼吸感。

### P0-3 删除数据来源 cache

前端删除 `result._source` 整段渲染（约 782-786 行那块 `数据来源: {result._source}`）。

### P1-4 五行卡缩高 + 人话解读

- `minHeight` 从 88 降到约 72，padding 同步收。
- 每张卡在「火 / 旺」下方增加一行极小字人话解读（11px，浅色），按五行+等级映射：
  - 火旺→今日易急躁 / 火衰→注意心血
  - 水旺→思虑活跃 / 水衰→注意补水休息
  - 木旺→行动力强 / 木衰→易疲惫
  - 土旺→沉稳务实 / 土衰→脾胃留意
  - 金旺→决断力佳 / 金衰→少争为宜
  - （平级可省略或显示「平稳」）
- 解读文案前端本地映射即可（key=五行+levelLabel），不走 AI，零成本零延迟。

### P1-5 幸运信息条下沉

- 把幸运信息（颜色/数字/方位）从顶部白卡内移出，下沉到宜忌之后、五行之前（或今日指引之前），做成独立极简条。
- 目的：顶部白卡聚焦「日期→断语」，阅读流为「氛围→行动→点缀」。

### P1-6 断语文案升级

通过 P0-1 的 `briefing` 字段 + prompt 文风要求达成：前半句具体利好/风险，后半句应对基调，专业术语增可信度。

## 四、验收标准

1. 顶部断语与底部今日指引内容不再重复（同一天刷新对比）。
2. 宜忌各显示 5 条，每条独立成行，无「·」连写。
3. 页面无「数据来源」字样。
4. 五行卡变矮，每张有人话解读小字。
5. 幸运信息条位置下沉，顶部白卡只剩日期+断语。
6. tsc --noEmit 通过，console 无 error。
7. 用 agent-browser 真机渲染截图验收（完整页面长截图 1 张），对照本 PRD 逐条核对。

## 五、注意事项

- 兼容旧缓存：briefing 字段为空时降级到 advice.slice(0,50)，不报错。
- 不破坏现有评分模块、命理脉络模块、今日之歌模块。
- 沿用 Frank 设计规范：禁止纯黑底选中态、边框/淡线高亮、暖米白底。
